# 🛠 Бот техподдержки колледжа

Telegram-бот для приёма и обработки заявок на обслуживание техники в колледже:
компьютеры, принтеры, проекторы, сеть, ПО и т.д.

Студенты и преподаватели оставляют заявки через простой пошаговый диалог,
а сотрудники техподдержки получают уведомления и управляют статусами заявок
прямо в чате.

## Возможности

**Для пользователей:**
- 📝 Создание заявки в 4 шага: категория техники → расположение → описание → контакт.
- 📋 Просмотр своих заявок и их статусов.
- 🔔 Автоматические уведомления при изменении статуса.

**Для техподдержки (администраторов):**
- 🔔 Мгновенные уведомления о новых заявках (в личку и/или в рабочий чат).
- 🛠 Список открытых заявок с кнопками управления.
- Действия по кнопкам: «Взять в работу», «Выполнено», «Отклонить» (с указанием причины).
- 📊 Статистика по статусам заявок.

Статусы: 🆕 Новая → 🛠 В работе → ✅ Выполнена / 🚫 Отклонена.

## Технологии

- [Node.js](https://nodejs.org/) (v18+)
- [node-telegram-bot-api](https://github.com/yagop/node-telegram-bot-api) — работа с Telegram Bot API (long polling)
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) — хранение заявок в SQLite
- [dotenv](https://github.com/motdotla/dotenv) — конфигурация через переменные окружения

## Установка и запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.

3. Скопируйте файл настроек и заполните его:

   ```bash
   cp .env.example .env
   ```

   Параметры в `.env`:
   - `BOT_TOKEN` — токен от @BotFather (обязательно).
   - `ADMIN_IDS` — ID сотрудников техподдержки через запятую. Свой ID можно
     узнать у бота [@userinfobot](https://t.me/userinfobot).
   - `SUPPORT_CHAT_ID` — (необязательно) ID группового чата техподдержки,
     куда дублировать новые заявки.
   - `DB_PATH` — путь к файлу базы данных (по умолчанию `./data/support.db`).

4. Запустите бота:

   ```bash
   npm start
   ```

   Для разработки с автоперезапуском: `npm run dev`.

## Структура проекта

```
index.js              точка входа: загрузка .env и запуск бота
src/
  config.js           конфигурация: админы, категории, статусы
  db.js               подключение к SQLite и схема таблиц
  tickets.js          бизнес-логика заявок (создание, статусы, статистика)
  keyboards.js        клавиатуры Telegram (меню, кнопки)
  bot.js              обработчики команд, сообщений и inline-кнопок
```

## Заметки

- Диалоговое состояние пользователя хранится в памяти процесса — рассчитано
  на запуск в одном экземпляре. Сами заявки надёжно сохраняются в SQLite.
- Чтобы добавить или изменить категории техники, отредактируйте массив
  `CATEGORIES` в `src/config.js`.
